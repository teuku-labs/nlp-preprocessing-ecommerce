## Deskripsi

Project ini bertujuan melakukan preprocessing terhadap dataset ulasan e-commerce Indonesia yang diperoleh dari Hugging Face.

Tahapan preprocessing meliputi:

- Case Folding
- Cleaning
- Tokenisasi
- Stopword Removal
- Stemming
